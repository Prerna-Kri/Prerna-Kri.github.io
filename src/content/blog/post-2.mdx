Modern vision models partition visual continuous signals into rigid patches ($16 \times 16$ or $8 \times 8$). While effective on standard datasets, this discrete bias fails when evaluating inputs across continuous zooms or varying camera sensors.

## The Operator Learning Paradigm

Instead of learning a mapping between finite-dimensional vector spaces $\mathbb{R}^n \to \mathbb{R}^m$, neural operators learn mappings between function spaces:

$$
\mathcal{G}_\theta : \mathcal{A} \to \mathcal{U}
$$

where $\mathcal{A}(\Omega; \mathbb{R}^{d_a})$ and $\mathcal{U}(\Omega; \mathbb{R}^{d_u})$ are Banach spaces of functions defined over a spatial domain $\Omega \subset \mathbb{R}^2$.

The kernel integral operator is given by:

$$
(\mathcal{K}v)(x) = \int_{\Omega} \kappa(x, y; \theta) v(y) \, dy
$$

By parameterizing $\kappa$ directly in the Fourier domain via the Fast Fourier Transform (FFT), we obtain resolution-invariant representations:

```python
import torch
import torch.nn as nn

class SpectralConv2d(nn.Module):
    def __init__(self, in_channels: int, out_channels: int, modes1: int, modes2: int):
        super().__init__()
        self.modes1 = modes1
        self.modes2 = modes2
        self.scale = 1 / (in_channels * out_channels)
        self.weights = nn.Parameter(
            self.scale * torch.rand(in_channels, out_channels, modes1, modes2, dtype=torch.cfloat)
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # x shape: [batch, in_channels, height, width]
        x_ft = torch.fft.rfft2(x)
        out_ft = torch.zeros_like(x_ft)
        out_ft[:, :, :self.modes1, :self.modes2] = torch.einsum(
            "bixy,ioxy->boxy",
            x_ft[:, :, :self.modes1, :self.modes2],
            self.weights
        )
        return torch.fft.irfft2(out_ft, s=(x.size(-2), x.size(-1)))
```

## Takeaways for Computer Vision

Treating images as continuous fields rather than discrete pixel grids opens up zero-shot super-resolution, principled rotation equivariance, and robust anomaly localization without retraining.
